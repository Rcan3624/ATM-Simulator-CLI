#ATM-Simulator-command-line-interface-version.-
An ATM Simulation program that I programmed in the C language(C11). Based on a school project back in 2019. No AI-generated code was used during the making of this program.



# Instructions
1. Double click the exe
2. Select an option with a number on your keyboard and press enter. 

3. Enter the username and password and press enter. 

4. Do the same thing with the transaction options
